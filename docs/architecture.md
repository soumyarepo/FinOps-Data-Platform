# Architecture

The FinOps Data Platform uses AWS for application hosting and data analytics. Application services run on Amazon EKS and are deployed through ArgoCD using a Helm chart. Docker images are built using GitHub Actions and stored in Amazon ECR.

Transaction data generated by the services is stored in Amazon S3. AWS Glue catalogs and transforms raw data. Amazon EMR runs Spark-based analytics jobs. Final datasets are stored in Amazon Redshift for reporting and downstream analytics.
